# Merenda Leonor — Guia de uso

Acesse o site pelo endereço [www.merendaleonor.publicvm.com](https://www.merendaleonor.publicvm.com/).

## Navegação

Use o menu no topo da página para ir diretamente a **Início**, **Cardápio**, **Dicas**, **Sugestões** ou **Sobre**. No rodapé, também estão disponíveis informações, contatos e links para outras páginas do projeto.

## Consultar o cardápio

Na seção **Cardápio da semana**, confira as refeições de segunda a sexta, com prato principal, acompanhamento e sobremesa. Se o botão **Atualizar cardápio** estiver disponível, clique nele para buscar a versão mais recente.

## Ver dicas

A seção **Dicas de alimentação** reúne orientações sobre higiene e convivência na hora das refeições.

## Enviar uma sugestão

1. Acesse **Sugestões** pelo menu.
2. Escreva sua ideia no campo **Sua sugestão**.
3. Clique em **Enviar por e-mail**.
4. Revise a mensagem aberta no Gmail e clique em **Enviar**.

Se o Gmail não abrir, use o link alternativo exibido no formulário para abrir um aplicativo de e-mail.

## Contato e outras informações

No rodapé, você encontra o e-mail, telefone, Instagram e endereço da escola, além de links para a política de privacidade, os termos de uso, a página sobre o projeto, os desenvolvedores e a central de ajuda.
